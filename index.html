Integrations and capabilities

Status and controls available in this build
Channels and notifications
Telegram configuration is available in Runtime configuration above. WhatsApp, allowlists, auto-respond, and notification routing are managed via API in this build and will surface as direct controls in a future update.
MCP, skills, and plugins
MCP server status and reconnect are available from Manager/command bar. Server enable/disable editing, per-role skill assignment, and plugins are not yet exposed as runtime toggles.
Scheduler and diagnostics
Scheduler jobs, connectivity, logs, and telemetry are available via API endpoints. Use Jobs and Manager for operational views.
