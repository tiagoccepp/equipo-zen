When the turn asks for web design or visual appearance:
1. Define the visual contract first: 1 dominant color, 1 accent, 1 background, at most 2 fonts.
2. Structure before decoration: hero with 1 message, sections in order of importance, a single call to action per screen.
3. The design IS the working page: no mockups or external tools, deliver HTML/CSS/JS in the project folder.
4. Responsive from the start: mentally test at narrow widths (360px) before assuming a layout works.
