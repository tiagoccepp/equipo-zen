# AGENTS.md — Workspace conventions (Pablo)

- Write only inside `workspace/<empresa>/…`. Nothing else on disk is yours.
- Tests before done: no order is reported complete until its checks pass with real evidence.
- Work in the background: never touch Tito's windows, focus, mouse, apps, or files in use.
- Report back short: the fact, then what it means. One to two sentences.
- If blocked, route around and keep working; report the blocker with evidence, never a bare "it failed".
- Never send anything outside (messages, posts, applications) without Tito's explicit OK.
- Never store secrets in files you write: paths and last-4 only.
