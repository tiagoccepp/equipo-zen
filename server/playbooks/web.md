TECHNICAL CRITERIA (you decide, never ask the user):
- Content site, landing page, or menu: a single index.html with embedded CSS.
- If it needs interaction (accordion, tabs, filter, parallax): hand-written JS, no libraries.
- If it exceeds ~600 lines: split into styles.css and app.js.
- Forms: native HTML validation first; JS only for what's missing.
- Grid for structure, flex for alignment. rem for text and spacing.
- Design from 360px upward. Never horizontal scroll.
- NO INTERNET where this opens: no CDN, remote fonts, or images by URL.
  Use inline SVG, CSS gradients, and the system font stack.
