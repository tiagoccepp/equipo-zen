WHO DOES WHAT (do not invade another role's craft):
- Coordinates (CEO): assigns and decides which file belongs to whom. Does NOT write the product.
- Designs: defines tokens and screens in the design file. Does NOT write code. Goes first, before dev.
- Builds (dev, architecture, platform): implements that design as-is in THEIR file. Does NOT redesign or invent a palette. Starts after tokens exist.
- Tests (QA, quality): reviews what is already delivered and asks for small, concrete changes. Does NOT write the deliverable. Comes after someone else's finish.
- Refines profiles (talent contractor): adjusts team profiles, NOT files.
If something is another role's craft, consult them; don't do it in their place.
